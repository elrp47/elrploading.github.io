# EliteRP · экран загрузки

Страница, которую видит игрок, пока подключается к серверу и докачивает
контент. Статическая: HTML, CSS и один JS-файл, без сборки и без зависимостей.
Из внешних файлов подтягиваются только знак сервера (`assets/logo.png`) и
снимки из `fones/` — оба слоя необязательные: пока они не пришли, экран уже
работает и показывает прогресс.

Оформление повторяет внутриигровой интерфейс (`EliteRP_UI`): тёмный фон,
скруглённые карточки, знак EliteRP, один акцентный цвет.

```
loadingscreen/
├── index.html
├── assets/
│   ├── style.css     оформление
│   ├── app.js        приём вызовов Garry's Mod, прогресс, советы, фоны
│   ├── config.js     ← единственный файл, который нужно править
│   └── logo.png      знак сервера в шапке
├── fones/            ← сюда кладутся фоновые снимки: 1.jpg, 2.jpg, 3.jpg…
│   └── 1.jpg
└── README.md
```

## 1. Настроить под свой сервер

Всё редактируемое лежит в `assets/config.js`:

| Поле                 | Что задаёт                                                   |
|----------------------|--------------------------------------------------------------|
| `fallbackName`       | Заголовок, пока сервер не прислал своё имя                   |
| `tagline`            | Строка под названием                                         |
| `links`              | Кнопки внизу левой карточки (сейчас Discord и правила)       |
| `tips`               | Советы игроку — карточки справа                              |
| `tipsPerPage`        | Сколько советов на одной странице (сейчас 3)                 |
| `tipInterval`        | Через сколько секунд меняется страница советов               |
| `backgroundFolder`   | Папка со снимками, по умолчанию `fones/`                     |
| `backgroundInterval` | Через сколько секунд меняется снимок                         |
| `backgroundMax`      | До какого номера искать файлы                                |
| `backgroundGap`      | Сколько пропущенных номеров подряд считать концом списка     |
| `backgrounds`        | Явный список путей — на случай нестандартных имён            |

Имя сервера, карту, режим, число мест и SteamID подставляет сама игра — эти
поля в конфиге не нужны.

Советы в `tips` сверены с кодом аддона: клавиши — по списку привязок из
`cl_eliterp_settings.lua` (`S.BindGroups`) и по жёстко зашитым слушателям
(`I`, `E`, `N`, `L`, `F6`, `G`, `T`, `M`, `F2` на дверь), названия вкладок — по
самому меню F4, чат-команды — по их обработчикам. Дописывая свой совет,
проверьте, что команда действительно существует: игрок будет читать это на
каждом заходе, и несуществующая клавиша в памятке дороже, чем пустое место.

> В окне загрузки Garry's Mod ссылки не открываются в браузере. Кнопки в
> `links` игрок может только прочитать, поэтому пишите адреса, которые не жалко
> набрать руками.

## 2. Фоновые снимки

Кладите картинки в `fones/` с именами по порядку: `1.jpg`, `2.jpg`, `3.jpg`…
Ничего прописывать в конфиг не нужно — скрипт сам перебирает номера и берёт
всё, что нашёл. Понимает `.jpg`, `.jpeg`, `.png`, `.webp`.

Как это устроено: списка файлов в папке браузеру не видно, поэтому имена просто
проверяются по очереди через `new Image()` — загрузилось значит есть. Поиск
останавливается после трёх пропущенных номеров подряд (`backgroundGap`), так
что **дыр в нумерации быть не должно**: `1, 2, 3`, а не `1, 5, 9`.

Кадры сменяются перекрёстным затуханием раз в 12 секунд с медленным наездом.
Пока снимок один — он просто стоит фоном. Поверх лежит затемнение, иначе
светлый бетон Сити-17 съедает текст.

Про размер: снимки едут игроку по тому же каналу, что и контент сервера. Держите
их в 1920×1080 и жмите в JPEG до 300–500 КБ — на 5–6 картинках это уже разница
между «фон появился сразу» и «фон появился к концу загрузки».

Если имена нестандартные (`screenshot_night.jpg` и т. п.), пропишите их руками:

```js
backgrounds: [
    "fones/screenshot_night.jpg",
    "fones/nexus.jpg"
]
```

Непустой `backgrounds` отключает автоподбор.

## 3. Выложить бесплатно (GitHub Pages)

`sv_loadingurl` требует публичный `http(s)`-адрес: файлы с диска игрока или
`localhost` не подойдут. Бесплатный вариант — GitHub Pages.

1. Заведите репозиторий (публичный — на приватных Pages платные) и положите в
   его **корень** содержимое этой папки: `index.html`, `assets/`, `fones/`.
   `index.html` должен оказаться в корне, а не внутри `loadingscreen/`.
2. **Settings → Pages → Source: Deploy from a branch**, ветка `main`, папка
   `/ (root)`. Сохранить.
3. Через минуту-две GitHub выдаст адрес вида
   `https://<логин>.github.io/<репозиторий>/`.
4. Откройте его в браузере: страница должна ожить и через три секунды запустить
   демонстрационный прогон прогресса. Заодно проверьте, что видно фон и знак —
   если нет, почти всегда дело в регистре имени файла: на GitHub Pages
   `1.JPG` и `1.jpg` — разные файлы, в отличие от Windows.

Альтернативы, тоже бесплатные и статические: Cloudflare Pages, Netlify,
Vercel. Разницы для экрана загрузки нет.

Обновление потом — обычный `git push`: Pages пересобирает сам за минуту. Если
у игроков остался старый экран, это кэш браузера — добавьте к адресу версию:
`.../?v=2`.

## 4. Подключить к серверу

В `server.cfg`:

```cfg
sv_loadingurl "https://ЛОГИН.github.io/РЕПОЗИТОРИЙ/"
```

Требования Garry's Mod к адресу:

* только `http://` или `https://`;
* адрес должен быть публичным — `localhost` и локальные адреса игрок не откроет;
* **обязателен завершающий слэш** либо прямая ссылка на `index.html`;
* длина строки — не больше 260 символов.

После правки перезапустите сервер: `sv_loadingurl` читается при старте.
Проверять нужно **не** через «Создать игру» в главном меню — там экран загрузки
не показывается; заходите на сервер через консоль клиента: `connect IP:порт`.

Если игрок видит стандартный синий экран Valve вместо этого — сервер не отдал
адрес: опечатка в `sv_loadingurl`, пропущенный слэш или конфиг не перечитан.

## 5. Как проверить, не поднимая сервер

Просто откройте `index.html` в браузере. Игра не позовёт свои функции, поэтому
через 3 секунды включится демонстрационный прогон: восемь файлов, прогресс до
100 % и переход в состояние «ГОТОВО». Так же можно проверить экран вручную из
консоли браузера:

```js
GameDetails("EliteRP · Сити-17", "", "rp_city17", 64, "STEAM_0:0:1", "darkrp");
SetFilesTotal(20);
DownloadingFile("materials/eliterp/logo.png");
SetFilesNeeded(7);   // 13 из 20 скачано
SetStatusChanged("Отправка клиентских данных");
SetFilesNeeded(0);   // загрузка завершена
```

> Открытие файла двойным щелчком (`file://`) годится для проверки вёрстки, но
> фоны при этом могут не найтись: часть браузеров не даёт странице с диска
> обращаться к соседним файлам. Проверять фоны надёжнее уже на Pages.

## Что вызывает Garry's Mod

Эти пять функций объявлены глобально в `app.js`. Если понадобится править
разметку — не переименовывайте их и не переносите внутрь обработчиков загрузки
документа: игра дотягивается до них раньше, чем документ успевает построиться.

| Функция                  | Когда вызывается                          |
|--------------------------|-------------------------------------------|
| `GameDetails(...)`       | Один раз, как только известны данные сервера |
| `SetFilesTotal(n)`       | Сколько файлов предстоит скачать          |
| `SetFilesNeeded(n)`      | Сколько ещё осталось; `0` — загрузка завершена |
| `DownloadingFile(name)`  | На каждый файл                            |
| `SetStatusChanged(text)` | Текстовый статус движка                   |

Конца загрузки отдельным вызовом движок не сообщает, поэтому завершением
считается момент, когда при известном общем числе не осталось нужных файлов.

### Параметры адреса

Кроме этих вызовов игра дописывает к `sv_loadingurl` данные подключения:

```
?steamid=76561198000000000&gamemode=darkrp&mapname=rp_city17&maxplayers=64
```

Они приходят вместе с самим адресом, то есть раньше любого `GameDetails`, —
поэтому сводка слева заполняется уже в первом кадре, а не через секунду.
Заодно это признак того, что страницу открыла игра: демонстрационный прогон при
таком заходе не запускается вовсе.

### Прогресс показывается настоящий

Полоса ведётся только по числам от движка — `SetFilesTotal` и `SetFilesNeeded`.
Никакого «прогресса по таймеру», как в прежнем `loading.html` в корне аддона,
здесь нет: там полоса ползла сама по себе на `Math.random()` и к реальной
загрузке отношения не имела.

Пока движок не сказал, сколько файлов предстоит скачать, процента не
существует: полоса идёт бегунком, а вместо числа стоит прочерк. Это честнее,
чем рисовать «0 %» или свою придуманную шкалу. Как только приходят числа —
бегунок сменяется настоящим процентом и счётчиком «N / M файлов».

Статус движка приходит по-английски: известные строки переводятся, незнакомая
показывается как есть (`translateStatus` в `app.js`).

Демонстрационный прогон включается, только если за 3 секунды игра не отозвалась
ничем — ни параметрами в адресе, ни вызовом. Раньше порог был 1,2 секунды без
проверки на вызовы, и на медленном канале демонстрация успевала врубиться
поверх настоящей загрузки и показать игроку выдуманные файлы.

## Совместимость

Код написан без современного синтаксиса — никаких `let`, `const`, стрелочных
функций, `?.` и `??`. На старых сборках Garry's Mod встроенный браузер всё ещё
Awesomium, и одна незнакомая конструкция гасит страницу целиком: игрок увидит
белый экран вместо загрузки. Если будете дописывать — держитесь того же уровня.
